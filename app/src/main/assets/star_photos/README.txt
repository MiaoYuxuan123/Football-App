Put your built-in carousel photos in this folder.

Supported formats:
- .jpg
- .jpeg
- .png
- .webp

Example:
app/src/main/assets/star_photos/messi.jpg
app/src/main/assets/star_photos/ronaldo.png

At runtime, Home carousel loading priority is:
1) user uploaded photos in app local storage
2) this assets/star_photos folder
3) fallback built-in gradient cards
