
Place preset coach voice files in this directory using these exact names:
- coach_good_shoot.mp3
- coach_good_dribble.mp3
- coach_good_pass.mp3
- coach_fix_shoot.mp3
- coach_fix_dribble.mp3
- coach_fix_pass.mp3
- coach_challenge_done.mp3
Supported formats: .mp3, .wav, .ogg
If a file is missing, the app keeps text feedback and skips voice for that cue.
